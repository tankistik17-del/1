# Задвижка трубопровода: 3D-модели чертежей дипломного проекта

Проект «Технология сборки-сварки корпуса задвижки трубопровода». Модели построены в CadQuery (ядро OpenCASCADE)
по листам PDF. Размеры, проставленные на чертежах, взяты как есть. Непроставленная геометрия снята с векторов PDF
(листы 1, 2, 6, 7 выполнены в М 1:1). Стандартные изделия (крепёж, кольца, штифты, баллоны, рельсы) выполнены по ГОСТ.

| Папка | Лист | Что смоделировано |
|---|---|---|
| `zadvizhka/` | 1 | Задвижка в сборе: корпус, крышка, клин, бугель, шпиндель, маховик Ø248, сальник, крепёж; проверка хода клина |
| `korpus/` | 2 | Сварной корпус: патрубки, стакан, фланцы, направляющие, дно, наплавка сёдел, швы №1–№3 (К3) |
| `prisposoblenie_1/` | 6 | Приспособление сварочное №1: пневмоцилиндры, рычажный зажим, поворотная ось-распределитель, кольца ГОСТ 9833-73, заготовка |
| `prisposoblenie_2/` | 7 | Приспособление сварочное №2: пневмоцилиндр Ø77, головка с рычагами-прихватами и фиксаторами, основание Ø200, заготовка; ход 0…30 мм проверен |
| `oborudovanie/` | 8 | Сварочный пост в натуральную величину (М 1:5 × 5): баллоны 40 л ГОСТ 949-73, ВС-300Б, ПДГ-312-5, горелка, стол, воздухоприёмник, шибер, воздуховод, рукава |
| `planirovka/` | 9 | Цех 36 × 18 м: колонны, фермы, фонарь, мостовой кран Q = 10 т, 6 кабин с оборудованием, столы, бункеры, пожарные щиты |

Листы 3–5 — плакаты и маршрутный техпроцесс, 3D-модели для них не нужны.

В каждой папке:
- `build.py` — параметрический скрипт;
- `out/*.step` — сборка с именами деталей и цветами;
- `out/*.glb`;
- `out/*.usdz` — для iPhone/iPad: открывается встроенным просмотром (Quick Look) из «Файлов», можно поставить в AR в натуральную величину;
- `out/parts_step/`, `out/parts_stl/` — каждая деталь отдельно;
- `out/spec.json` — спецификация;
- `renders/` — виды и разрезы для сверки с чертежом;
- `NOTES.md` — проверенные размеры, допущения, противоречия в чертеже и расхождения с ГОСТ.

Корпус собирается один раз: модели листов 1 и 8 подключают `korpus/build.py`, а не копируют его.

## Сборка и просмотр

```bash
pip install cadquery
for d in korpus zadvizhka prisposoblenie_1 prisposoblenie_2 oborudovanie planirovka; do (cd $d && python3 build.py); done
for g in */out/*.glb; do python3 ../tools/glb_to_usdz.py "$g"; done   # USDZ для iPad (pip install usd-core trimesh)
cd viewer && ZADV_PDF=<путь к PDF> python3 make_viewer.py && cd .. && python3 -m http.server   # открыть /viewer/
```

## Что стоит знать

Все модели прошли независимую проверку: размеры, виды и разрезы сравнивались с чертежом, проверялись комплектность
позиций, ГОСТ и пересечения деталей. После проверки выполнены исправления. Замечания к самим чертежам:

- Лист 2: справочные размеры 160* и 268* противоречат друг другу и размерам фланцев Ø210. В модели 155 и 260 по
  размерной цепи листа 1 (181* + 105 = 286*).
- Трубы Ø111×6 и Ø130×6 и фланцы Ø210 / Ø180 не совпадают с рядами ГОСТ 8732-78 и ГОСТ 12820/12815 (DN100:
  D = 215). В модели взяты значения чертежа.
- В технических требованиях указан «ГОСТ 2246-79», правильно ГОСТ 2246-70.
- На листах 1, 6 и 7 нет спецификации. Наименования позиций определены по конструкции. Детали без номеров
  позиций помечены в `spec.json`.

## Файлы для флешки (Windows, без программ и интернета)

```bash
python3 tools/make_package.py <PDF чертежей> <папка>        # задвижка: 3D-просмотр (один HTML), альбом PDF, STEP, GLB
python3 tools/make_package_kran.py <папка>                   # шаровой кран DN 50
```

Каждый файл самостоятельный. «… - 3D просмотр.html» содержит внутри three.js, шрифты PT, все модели и листы
чертежей и открывается двойным щелчком в Edge или Chrome. Библиотеки и шрифты для встраивания лежат
в `viewer/offline/` (лицензии MIT и OFL рядом).

## Разбор сварочных приспособлений

`razbor/` — страница «Как работают сварочные приспособления»: пошаговые 3D-анимации листов 6 и 7
(установка деталей, путь воздуха, зажим с кинематикой рычагов, прихватка и кольцевая сварка с поворотом,
разжим), пневмосхемы, расчёт усилий, посадки, позиции. `python3 razbor/make_razbor.py <папка>` пишет
`razbor/index.html` (веб) и самодостаточный «Приспособления - разбор.html».
`python3 razbor/make_video.py <папка>` записывает то же самое в два видео MP4 (H.264, 1280×720, подписи шагов)
и PDF с кадрами каждого шага — для iPad и телефонов, где веб-страница не открывается. Готовые файлы лежат в `razbor/out/`.

## Тепловой процесс сварки

`teplo/` — страница «Тепловой процесс сварки и ЗТВ»: расчёт по Рыкалину (δкр, t₈/₅, ширина ЗТВ, сверка
EN 1011-2) с изменяемыми режимами, анимация теплового поля движущейся дуги (тонкая пластина) и численный
расчёт теплопроводности в сечении швов №1 и №2 (сетка 0,25 мм, выполняется в браузере): поле температур
во времени, строение ЗТВ стали 20, термические циклы. `thermal.py` — эталонная реализация на numpy
(проверка: пластина 6 мм, t₈/₅ = 0,95–0,99 с численно против 1,02 с по Рыкалину).
`python3 teplo/make_teplo.py <папка>` — самодостаточный HTML; `python3 teplo/make_video.py <папка>` — MP4 и PDF.

## Сборка-сварка корпуса и экономика участка

`process/` — 3D-анимация техпроцесса по операциям 020–050 (детали, растущие швы, нормы времени,
гидроиспытание 1,6 МПа) и экономическая часть: нормирование по длинам швов из модели, калькуляция
себестоимости корпуса, мощность участка (узкое место — место контроля), точка безубыточности, запас
финансовой прочности, чувствительность; все исходные данные редактируются на странице.
`calc.py` — эталонный расчёт (out/economics.json), `make_process.py` — страница, `make_video.py` — MP4 и PDF.
