# Статистика групп

Страница, куда раз в неделю загружаются таблицы групп (.xlsx). Она разбирает их прямо в браузере и показывает статистику по каждой группе и по всем вместе.

- `parser.js` разбирает листы «Посещаемость», «Успеваемость», «Пробники», «КЭС» и «ДР», включая цвет заливки ячеек, и считает показатели и статусы учеников.
- `app.tpl.html` содержит интерфейс: сводку, вкладки групп, карточки учеников, графики и настройки. История загрузок хранится в базе артефакта.
- `node build.cjs` собирает из них один файл `stats.html` (он в .gitignore).

Таблицы учеников в репозиторий не кладутся.
