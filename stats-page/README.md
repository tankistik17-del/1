# Статистика групп

Страница, куда раз в неделю загружаются таблицы групп (.xlsx). Она разбирает их прямо в браузере и показывает статистику по каждой группе и по всем вместе.

- `parser.js` разбирает листы «Посещаемость», «Успеваемость», «Пробники», «КЭС» и «ДР», включая цвет заливки ячеек, и считает показатели и статусы учеников.
- `app.tpl.html` содержит интерфейс: сводку, вкладки групп, карточки учеников, графики и настройки. История загрузок хранится в базе артефакта.
- `node build.cjs` собирает из них `stats.html` — страницу для Claude: владелец видит свои группы и историю (хранятся в базе артефакта), любой другой по той же ссылке получает личную копию в своём браузере.
- `node build-standalone.cjs <путь к xlsx.full.min.js> "Статистика групп.html"` собирает отдельный файл для компьютера: SheetJS встроен, работает без интернета и без Claude, данные хранятся в браузере (`localStorage`), в «Настройках» есть резервная копия. На iPhone локальные HTML-файлы открываются в предпросмотре без скриптов, поэтому там нужна ссылка.
- Собранные файлы в .gitignore.

Таблицы учеников в репозиторий не кладутся.
