# Живая математика ОГЭ

Интерактивные визуализации тем ОГЭ по математике для занятий с репетитором. Откройте `index.html` в браузере (нужен интернет для загрузки Three.js и шрифтов).

- **Теорема Пифагора в 3D** — квадраты на сторонах треугольника превращены в баки с водой: вода из двух баков на катетах ровно заполняет бак на гипотенузе (задания 15–19).
- **Парабола** — ползунки a, b, c; вершина, ось симметрии, корни, дискриминант и пересечение с Oy (задание 11).
- **Вписанный угол** — перетаскиваемые точки на окружности, вписанный угол = ½ центрального (задание 16).

В каждой теме — случайно генерируемые задачи в стиле ОГЭ с проверкой ответа и подсказками.
