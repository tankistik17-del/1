# Пульт удержания

Рабочий прототип дашборда удержания учеников для репетитора по математике.
Показывает индекс удержания 0–100 по каждому ученику (посещаемость, домашки,
пробники), подсвечивает зоны риска и хранит историю контактов.

- **Вход по паролю**: два аккаунта — репетитор и администратор. Оба видят одни и те же данные.
- **Данные общие**: хранятся на сервере (SQLite), а не в браузере.
- **Автоматическая синхронизация** с Google Sheets: при старте сервера, по расписанию (каждые 30 минут) и по кнопке.
- **Загрузка .xlsx** журналов перетаскиванием или кнопкой — как в исходном прототипе.
- Пока не загружен ни один журнал, показываются демо-данные.

## Быстрый старт локально

Без командной строки: установите [Node.js LTS](https://nodejs.org), затем
двойной клик по `СТАРТ-Windows.bat` (Windows) или `старт-mac.command` (macOS,
первый раз — правый клик → «Открыть»). Браузер откроется сам.

Либо вручную (нужен Node.js 22.5+; SQLite встроен в Node, внешняя база не нужна):

```bash
npm install
npm start
# открыть http://localhost:3000
```

Пароли по умолчанию: репетитор — `tutor123`, администратор — `admin123`.
**Обязательно смените их** через переменные окружения (см. ниже).

## Переменные окружения

| Переменная | Что делает | По умолчанию |
|---|---|---|
| `PORT` | порт сервера | `3000` |
| `TUTOR_PASSWORD` | пароль репетитора (применяется при каждом старте) | `tutor123` |
| `ADMIN_PASSWORD` | пароль администратора | `admin123` |
| `DB_PATH` | путь к файлу базы SQLite | `./data/retention.db` |
| `SYNC_INTERVAL_MIN` | период автосинка с Google Sheets, минуты | `30` |
| `GS_URL` | URL веб-приложения Apps Script (вместо настройки в интерфейсе) | — |
| `GS_TOKEN` | секретный токен для Apps Script | — |

`GS_URL`/`GS_TOKEN` удобны на хостинге без постоянного диска: даже если база
сотрётся при передеплое, сервер сам заново заберёт все журналы из таблицы при старте.

## Подключение Google Sheets (3 шага)

1. В своей таблице: «Расширения» → «Apps Script». Вставьте код из окна
   «⚙ → Код для Apps Script» в приложении (он же ниже), замените `YOUR_TOKEN`
   на придуманную строку.
2. «Развернуть» → «Новое развертывание» → тип «Веб-приложение», доступ «Все».
   Скопируйте URL вида `https://script.google.com/macros/s/.../exec`.
3. В приложении нажмите «⊕ Sheets», вставьте URL и токен, нажмите «Синхронизировать».

```js
const TOKEN = 'YOUR_TOKEN';

function doGet(e) {
  if ((e.parameter.token || '') !== TOKEN) {
    return ContentService
      .createTextOutput(JSON.stringify({error: 'unauthorized'}))
      .setMimeType(ContentService.MimeType.JSON);
  }
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheets = ss.getSheets().map(s => ({
    name: s.getName(),
    rows: s.getDataRange().getDisplayValues()
  }));
  return ContentService
    .createTextOutput(JSON.stringify({name: ss.getName(), sheets}))
    .setMimeType(ContentService.MimeType.JSON);
}
```

Формат листов таблицы:
- **Журнал группы**: в первых строках должны встречаться слова «ученик» (колонка с ФИО)
  и «неделя» (заголовки недель); колонки домашек — «ДЗ 1», «ДЗ 2 макс 8» и т.п.
  Пропуск — пустая ячейка или «не прислал».
- **Пробники** (необязательно): колонки «ФИО», «Пробник 1», «Пробник 2», … Пропуск — «не сдан».
- Если групп несколько — по листу на группу; лист пробников называйте так же,
  как журнал (например, «ОГЭ-А журнал» и «ОГЭ-А пробники»).

## Деплой (пример — Render)

1. Создайте аккаунт на [render.com](https://render.com), «New → Web Service»,
   укажите этот репозиторий (файл `render.yaml` уже настроен).
2. Задайте переменные `TUTOR_PASSWORD`, `ADMIN_PASSWORD`, `GS_URL`, `GS_TOKEN`.
3. Готово: у вас будет ссылка вида `https://….onrender.com` — заходите с любого
   устройства, вы и администратор, каждый под своим паролем.

На бесплатном тарифе Render нет постоянного диска: отметки звонков и история
недельных дельт стираются при передеплое, но журналы восстанавливаются из
Google Sheets автоматически. Для полного сохранения подключите диск
(`DB_PATH=/data/retention.db`) или используйте Railway/Fly/VPS — есть `Dockerfile`.

## Структура

```
server/          Express-сервер: авторизация, API, синк из Google Sheets
  index.js       маршруты и статика
  db.js          SQLite (node:sqlite): пользователи, сессии, группы, снапшоты, звонки
  gsync.js       синхронизация с Apps Script по расписанию
shared/          распознавание листов (используется сервером и браузером)
public/          интерфейс (Vue 3, всё вендорено — CDN не нужен)
  index.html     дашборд: обзор / группа / карточка ученика
  login.html     страница входа
  js/app.js      логика: расчёт индекса, разбор .xlsx, работа с API
```

Расчёт индекса удержания перенесён без изменений из исходного прототипа
(`_assess`, `_mockAssess`, `_computeStudents` в `public/js/app.js`).
