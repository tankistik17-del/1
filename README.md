# Горячая резина

Дрифт-гонки для iPad с видом сверху. Работают в Safari, устанавливать ничего не нужно.

## Как играть

- Газ жмётся сам, ты только рулишь.
- Держи палец на левой половине экрана, чтобы повернуть влево, на правой половине — вправо.
- Коснись экрана двумя пальцами — это ручник, машину уведёт в занос.
- За длинный занос дают очки, а серия заносов подряд увеличивает множитель.

**Режимы:** «Гонка» (3 круга против трёх соперников), «Дрифт-зачёт» (90 секунд на очки за занос), «На время» (лучший круг).
**Трассы:** «Кольцо», «Порт», «Серпантин». **Машины:** хэтчбек, купе, маслкар. **Сложность:** легко, нормально, сложно.

## Запуск

Открой `index.html` в браузере. Внешние зависимости не нужны, только шрифты Google Fonts.

`node tools/build.mjs` собирает всю игру в один файл `dist/game.html` (фрагмент для публикации как Artifact).

## Файлы

- `index.html`: разметка и стили меню.
- `js/core.js`: оболочка (меню, игровой цикл, касания, звук, сохранения, пауза и экран результатов).
- `js/drift.js`: сама игра (трассы, физика, соперники, счёт).
- `tools/build.mjs`: сборка в один файл.
