# Лист «Сводка» для таблицы репетитора

Формулы и скрипт для двух новых листов Google Таблицы: «Сводка» (вся группа: плитки, «требует внимания», светофор по ученикам, посещаемость по занятиям, КЭС, входной пробник, дни рождения) и «Ученик» (карточка одного ученика с текстом для родителей).

Сводка читает листы «Успеваемость», «Посещаемость», «Пробники», «КЭС» и «ДР» и ищет учеников по имени. Формулы — для русской локали таблицы (аргументы через «;», столбцы в `{…}` через «\\»). Каждая формула здесь записана одной строкой: так её можно вставить прямо в ячейку.


**Быстрый способ:** [`build-dashboard.gs`](build-dashboard.gs) — один скрипт: создаёт листы «Сводка» и «Ученик» со всеми формулами ниже и переводит цветные отметки посещаемости в «был» / «н». Расширения → Apps Script → вставить код → выбрать `setupDashboard` → Выполнить.

## 1. Посещаемость: цвет → «был» и «н»

Формулы не видят цвет заливки. Скрипт [`attendance-colors-to-text.gs`](attendance-colors-to-text.gs) один раз записывает «был» в зелёные ячейки и «н» в красные (чёрные, «ещё не учился», остаются пустыми) и добавляет условное форматирование.

1. Файл → Создать копию (на всякий случай).
2. Расширения → Apps Script → вставить код → Сохранить.
3. Выбрать `attendanceColorsToText` → Выполнить → разрешить доступ.
4. Новые отметки — выпадающим списком «был» / «н» (Вставка → Раскрывающийся список).


## 2. Лист «Сводка»: таблица учеников

Строка 14 — заголовки: A Статус, B Ученик, C Цель, D Посещения, E %, F ДЗ, G Тесты, H Конспекты, I Входной, J КЭС, K Telegram; служебные M Подряд, N ДЗ сдано, O ДЗ задано, P ДЗ %. B15 — один раз, остальное — в строку 15 и вниз до 44. Скрыть M–P, закрепить A–B. Формат E, G, H, P — процент.

**Сводка · B15 — Список учеников**

Одна формула на весь столбец: имена сами подтянутся с листа «Посещаемость».

```
=FILTER('Посещаемость'!A2:A40; 'Посещаемость'!A2:A40 <> "")
```

**Сводка · A15 — Статус ученика**

Риск: посещаемость ниже 70%, или 2+ пропуска подряд сейчас, или ни одного ДЗ из двух и больше. Внимание: посещаемость ниже 90%, меньше половины ДЗ или нет входного пробника.

```
=IF($B15 = ""; ""; IFS( AND(E15 <> ""; E15 < 70%); "риск"; AND(M15 <> ""; M15 >= 2); "риск"; AND(N(O15) >= 2; N(N15) = 0); "риск"; AND(E15 <> ""; E15 < 90%); "внимание"; AND(P15 <> ""; P15 < 50%); "внимание"; I15 = ""; "внимание"; TRUE; "норм" ))
```

**Сводка · C15 — Цель**

Достаёт «4» из «Имя Фамилия (4)». Ученик ищется по началу имени, поэтому скобки в Успеваемости можно оставить.

```
=IF($B15 = ""; ""; IFERROR(REGEXEXTRACT( INDEX('Успеваемость'!$A:$A; MATCH($B15 & "*"; 'Успеваемость'!$A:$A; 0)); "\((.+)\)"); "—"))
```

**Сводка · D15 — Посещения: полоска по датам**

Столбик вверх — был, вниз — «н», пусто — ещё не учился.

```
=IF($B15 = ""; ""; IFERROR(LET( a_head; 'Посещаемость'!$1:$1; a_row; INDEX('Посещаемость'!$1:$100; MATCH($B15; 'Посещаемость'!$A$1:$A$100; 0); 0); a_marks; FILTER(a_row; COLUMN(a_head) > 1; a_head <> ""); SPARKLINE(ARRAYFORMULA(IF(a_marks = "был"; 1; IF(a_marks = "н"; -1; 0))); {"charttype"\"winloss"; "color"\"#0CA30C"; "negcolor"\"#D03B3B"}) ); ""))
```

**Сводка · E15 — Посещаемость, %**

```
=IF($B15 = ""; ""; IFERROR(LET( a_row; INDEX('Посещаемость'!$1:$100; MATCH($B15; 'Посещаемость'!$A$1:$A$100; 0); 0); n_ok; COUNTIF(a_row; "был"); n_miss; COUNTIF(a_row; "н"); IF(n_ok + n_miss = 0; ""; n_ok / (n_ok + n_miss)) ); ""))
```

**Сводка · F15 — ДЗ: «сдано из задано»**

Числа берутся из скрытых столбцов N и O.

```
=IF(OR($B15 = ""; O15 = ""); ""; N15 & " из " & O15)
```

**Сводка · G15 — Тесты, средний %**

Столбцы, где в заголовке есть «правильн». Максимум формула берёт из «(макс8)» прямо в заголовке.

```
=IF($B15 = ""; ""; IFERROR(LET( u_head; 'Успеваемость'!$2:$2; u_row; INDEX('Успеваемость'!$1:$100; MATCH($B15 & "*"; 'Успеваемость'!$A$1:$A$100; 0); 0); is_test; ARRAYFORMULA(REGEXMATCH(u_head & ""; "(?i)правильн") * ISNUMBER(u_row)); t_max; ARRAYFORMULA(IFERROR(VALUE(REGEXEXTRACT(u_head & ""; "макс\s*(\d+)")); 0)); t_got; ARRAYFORMULA(IFERROR(u_row * 1; 0)); SUMPRODUCT(is_test; t_got) / SUMPRODUCT(is_test; t_max) ); ""))
```

**Сводка · H15 — Конспекты, %**

Столбцы со словом «конспект»: «прислал…» делить на все отметки.

```
=IF($B15 = ""; ""; IFERROR(LET( u_head; 'Успеваемость'!$2:$2; u_row; INDEX('Успеваемость'!$1:$100; MATCH($B15 & "*"; 'Успеваемость'!$A$1:$A$100; 0); 0); k_ok; COUNTIFS(u_head; "*конспект*"; u_row; "прислал*"); k_all; COUNTIFS(u_head; "*конспект*"; u_row; "*прислал*"); IF(k_all = 0; ""; k_ok / k_all) ); ""))
```

**Сводка · I15 — Входной пробник**

```
=IF($B15 = ""; ""; IFERROR(INDEX('Пробники'!$C:$C; MATCH($B15; 'Пробники'!$A:$A; 0)); ""))
```

**Сводка · J15 — КЭС: пройденные шаги**

● — шаг пройден, ○ — нет. Ученик ищется по имени в столбце B листа КЭС.

```
=IF($B15 = ""; ""; IFERROR(LET( k_head; 'КЭС'!$1:$1; k_row; INDEX('КЭС'!$1:$100; MATCH($B15; 'КЭС'!$B$1:$B$100; 0); 0); n_done; COUNTIFS(k_head; "Довели*"; k_row; 1); n_all; COUNTIF(k_head; "Довели*"); REPT("●"; n_done) & REPT("○"; n_all - n_done) ); "нет в КЭС"))
```

**Сводка · K15 — Ссылка «написать» в Telegram**

Ник берётся из КЭС. Нажимаешь на ячейку — открывается чат с учеником.

```
=IF($B15 = ""; ""; LET( nick; IFERROR(INDEX('КЭС'!$A:$A; MATCH($B15; 'КЭС'!$B:$B; 0)); ""); IF(nick = ""; "—"; HYPERLINK("https://t.me/" & SUBSTITUTE(nick; "@"; ""); "написать " & nick)) ))
```

**Сводка · M15 — Пропусков подряд сейчас (скрытый)**

Сколько последних отметок подряд — «н».

```
=IF($B15 = ""; ""; IFERROR(LET( a_head; 'Посещаемость'!$1:$1; a_row; INDEX('Посещаемость'!$1:$100; MATCH($B15; 'Посещаемость'!$A$1:$A$100; 0); 0); a_marks; FILTER(a_row; COLUMN(a_head) > 1; (a_row = "был") + (a_row = "н") > 0); COLUMNS(a_marks) - IFERROR(XMATCH("был"; a_marks; 0; -1); 0) ); ""))
```

**Сводка · N15 — ДЗ сдано (скрытый)**

Столбцы, заголовок которых начинается с «дз», и в ячейке ученика стоит балл.

```
=IF($B15 = ""; ""; IFERROR(LET( u_head; 'Успеваемость'!$2:$2; u_row; INDEX('Успеваемость'!$1:$100; MATCH($B15 & "*"; 'Успеваемость'!$A$1:$A$100; 0); 0); SUMPRODUCT(ARRAYFORMULA(REGEXMATCH(u_head & ""; "(?i)^\s*дз") * ISNUMBER(u_row))) ); ""))
```

**Сводка · O15 — ДЗ задано (скрытый)**

Все столбцы «дз…», кроме ячеек с прочерком «—».

```
=IF($B15 = ""; ""; IFERROR(LET( u_head; 'Успеваемость'!$2:$2; u_row; INDEX('Успеваемость'!$1:$100; MATCH($B15 & "*"; 'Успеваемость'!$A$1:$A$100; 0); 0); SUMPRODUCT(ARRAYFORMULA(REGEXMATCH(u_head & ""; "(?i)^\s*дз") * (1 - REGEXMATCH(u_row & ""; "^\s*[-—–]\s*$")))) ); ""))
```

**Сводка · P15 — ДЗ, % (скрытый)**

```
=IF(OR($B15 = ""; N(O15) = 0); ""; N15 / O15)
```

## 3. Плитки (строки 3–5)

Каждая плитка — две объединённые ячейки: A–B, C–D, E–F, G–H, I–J, K–L.

**Сводка · A2 — Подпись под заголовком**

```
="Учеников: " & COUNTA(B15:B44) & " · обновлено " & TEXT(TODAY(); "dd.mm.yyyy")
```

**Сводка · A4 — Плитка «Посещаемость»**

Все «был» и «н» с листа «Посещаемость». Формат ячейки — процент.

```
=LET( n_ok; COUNTIF('Посещаемость'!$2:$100; "был"); n_miss; COUNTIF('Посещаемость'!$2:$100; "н"); IFERROR(n_ok / (n_ok + n_miss); "—") )
```

**Сводка · A5 — Тренд под плиткой посещаемости**

Линия по занятиям. Берёт столбец S из блока «Посещаемость по занятиям».

```
=SPARKLINE(S15:S60; {"charttype"\"line"; "ymin"\0; "ymax"\1; "empty"\"ignore"; "color"\"#2A78D6"; "linewidth"\2})
```

**Сводка · C4 — Плитка «ДЗ сдано»**

Сумма сданных ДЗ по всем ученикам делить на сумму заданных. Под плиткой (C5): =SUM(N15:N44) & " из " & SUM(O15:O44) & " сдано".

```
=IFERROR(SUM(N15:N44) / SUM(O15:O44); "—")
```

**Сводка · E4 — Плитка «Тесты»**

Средний % правильных ответов; ученики без тестов не учитываются. Под плиткой (E5): ="учеников с тестами: " & COUNT(G15:G44).

```
=IFERROR(AVERAGE(G15:G44); "—")
```

**Сводка · G4 — Плитка «Входной пробник»**

Под плиткой (G5): ="писали " & COUNT(I15:I44) & " из " & COUNTA(B15:B44).

```
=IFERROR(AVERAGE(I15:I44); "—")
```

**Сводка · I4 — Плитка «Дошли до 1-го ДЗ»**

Сколько единиц в столбце «Довели до 1 дз» на листе КЭС; заголовок в формуле должен совпадать с ним. Под плиткой (I5): ="из " & COUNTA(B15:B44).

```
=COUNTIF(INDEX('КЭС'!$1:$100; 0; MATCH("Довели до 1 дз"; 'КЭС'!$1:$1; 0)); 1)
```

**Сводка · K4 — Плитка «В зоне риска»**

Под плиткой (K5): ="внимание " & COUNTIF(A15:A44; "внимание") & " · норм " & COUNTIF(A15:A44; "норм").

```
=COUNTIF(A15:A44; "риск")
```

## 4. «Требует внимания» (C8:C12)

Подписи в A8:A12, формулы в C8:C12; объединить C–K, включить перенос.

**Сводка · C8 — Посещаемость ниже 70%**

```
=IFERROR(TEXTJOIN(", "; TRUE; FILTER(B15:B44 & " (" & TEXT(E15:E44; "0%") & ")"; E15:E44 <> ""; E15:E44 < 70%) ); "—")
```

**Сводка · C9 — Пропадают: 2+ пропуска подряд**

```
=IFERROR(TEXTJOIN(", "; TRUE; FILTER(B15:B44 & " (" & M15:M44 & ")"; M15:M44 <> ""; M15:M44 >= 2) ); "—")
```

**Сводка · C10 — Не сдали ни одного ДЗ**

```
=IFERROR(TEXTJOIN(", "; TRUE; FILTER(B15:B44; O15:O44 <> ""; O15:O44 >= 2; N15:N44 = 0) ); "—")
```

**Сводка · C11 — Не писали входной пробник**

```
=IFERROR(TEXTJOIN(", "; TRUE; FILTER(B15:B44; B15:B44 <> ""; I15:I44 = "") ); "—")
```

**Сводка · C12 — Молодцы: все занятия и все ДЗ**

```
=IFERROR(TEXTJOIN(", "; TRUE; FILTER(B15:B44; E15:E44 = 1; P15:P44 = 1) ); "—")
```

## 5. Блоки справа: график, КЭС, пробник, ДР

Формулы со списками (R15, U15, Y15, AF15) разворачиваются вниз — ниже них должно быть пусто. График: выделить R14:S60 → Вставка → Диаграмма → вертикальные столбцы.

**Сводка · R15 — Посещаемость по занятиям (для графика)**

Выдает таблицу «занятие — % пришедших». Потом: выдели R14:S60 → Вставка → Диаграмма → вертикальные столбцы.

```
=LET( a_head; 'Посещаемость'!$1:$1; a_data; 'Посещаемость'!$2:$100; n_ok; BYCOL(a_data; LAMBDA(c_col; COUNTIF(c_col; "был"))); n_miss; BYCOL(a_data; LAMBDA(c_col; COUNTIF(c_col; "н"))); TRANSPOSE(FILTER( VSTACK(a_head; ARRAYFORMULA(IFERROR(n_ok / (n_ok + n_miss); ""))); COLUMN(a_head) > 1; a_head <> ""; ARRAYFORMULA(n_ok + n_miss > 0))) )
```

**Сводка · U15 — КЭС по шагам**

Шаг и сколько учеников его прошли. Полоску рисует W15: =IF(V15 = ""; ""; SPARKLINE(V15; {"charttype""bar"; "max"COUNTA($B$15:$B$44); "color1""#2A78D6"})).

```
=LET( k_head; 'КЭС'!$1:$1; k_data; 'КЭС'!$2:$100; n_yes; BYCOL(k_data; LAMBDA(c_col; COUNTIF(c_col; 1))); TRANSPOSE(FILTER( VSTACK(ARRAYFORMULA(SUBSTITUTE(k_head & ""; "Довели до "; "")); n_yes); ARRAYFORMULA(REGEXMATCH(k_head & ""; "^Довели")))) )
```

**Сводка · W15 — Полоска для шага КЭС**

```
=IF(V15 = ""; ""; SPARKLINE(V15; {"charttype"\"bar"; "max"\COUNTA($B$15:$B$44); "color1"\"#2A78D6"}))
```

**Сводка · Y15 — Входной пробник по убыванию**

Выдаёт три столбца: ученик, балл, цель.

```
=IFERROR(SORT(FILTER(HSTACK(B15:B44; I15:I44; C15:C44); ISNUMBER(I15:I44)); 2; FALSE); "")
```

**Сводка · AB15 — Оценка по баллу**

Пороги ОГЭ: «3» от 8, «4» от 15, «5» от 22. Для базы ЕГЭ — 7, 12, 17.

```
=IF(Z15 = ""; ""; IFS(Z15 >= 22; 5; Z15 >= 15; 4; Z15 >= 8; 3; TRUE; 2))
```

**Сводка · AC15 — Полоска балла с цветом оценки**

Максимум 31 — ОГЭ. Для базы ЕГЭ поставь 21.

```
=IF(Z15 = ""; ""; SPARKLINE(Z15; {"charttype"\"bar"; "max"\31; "color1"\IF(AB15 >= 4; "#0CA30C"; IF(AB15 = 3; "#FAB219"; "#D03B3B"))}))
```

**Сводка · AD15 — Сколько баллов до цели**

Цель «3-4» считается по первой цифре.

```
=IF(OR(Z15 = ""; AA15 = ""; AA15 = "—"); ""; LET( goal_n; VALUE(LEFT(AA15)); need_n; IFS(goal_n >= 5; 22; goal_n = 4; 15; TRUE; 8); IF(Z15 >= need_n; "цель есть"; "не хватает " & (need_n - Z15)) ))
```

**Сводка · AF15 — Дни рождения на 2 недели вперёд**

Я не видел лист ДР. Формула считает, что в A — имя, в B — дата рождения.

```
=LET( d_name; 'ДР'!A2:A; d_date; 'ДР'!B2:B; d_left; ARRAYFORMULA(IF(ISNUMBER(d_date); MOD(DATE(YEAR(TODAY()); MONTH(d_date); DAY(d_date)) - TODAY(); 365); "")); IFERROR(SORT(FILTER(HSTACK(d_name; ARRAYFORMULA(TEXT(d_date; "dd.mm")); d_left); d_left <> ""; d_left <= 14); 3; TRUE); "в ближайшие 2 недели — нет") )
```

## 6. Лист «Ученик»

В B2 — выпадающий список из имён, остальное подстраивается под выбранного ученика.

**Ученик · B2 — Выбор ученика**

Это не формула: Вставка → Раскрывающийся список → «Из диапазона» → Сводка!B15:B44.

```
'Сводка'!B15:B44
```

**Ученик · A5 — Показатели из «Сводки»**

В соседних ячейках та же формула, меняется только последний столбец: C — цель, E — посещаемость, F — ДЗ, G — тесты, H — конспекты, I — входной, J — КЭС.

```
=XLOOKUP($B$2; 'Сводка'!$B$15:$B$44; 'Сводка'!$A$15:$A$44; "")
```

**Ученик · B7 — Даты занятий**

```
=FILTER('Посещаемость'!$1:$1; COLUMN('Посещаемость'!$1:$1) > 1; 'Посещаемость'!$1:$1 <> "")
```

**Ученик · B8 — Отметки ученика**

Раскрась условным форматированием: «был» — зелёный, «н» — красный.

```
=LET( a_head; 'Посещаемость'!$1:$1; a_row; INDEX('Посещаемость'!$1:$100; MATCH($B$2; 'Посещаемость'!$A$1:$A$100; 0); 0); FILTER(a_row; COLUMN(a_head) > 1; a_head <> "") )
```

**Ученик · A11 — Сообщение родителям**

Объедини A11:I11 и включи перенос текста. Текст пересобирается при выборе другого ученика.

```
=LET( s_name; $B$2; a_head; 'Посещаемость'!$1:$1; a_row; INDEX('Посещаемость'!$1:$100; MATCH(s_name; 'Посещаемость'!$A$1:$A$100; 0); 0); n_ok; COUNTIF(a_row; "был"); n_miss; COUNTIF(a_row; "н"); missed; IFERROR(TEXTJOIN(", "; TRUE; ARRAYFORMULA(TEXT(FILTER(a_head; a_row = "н"); "dd.mm"))); ""); hw_ok; N(XLOOKUP(s_name; 'Сводка'!$B$15:$B$44; 'Сводка'!$N$15:$N$44; 0)); hw_all; N(XLOOKUP(s_name; 'Сводка'!$B$15:$B$44; 'Сводка'!$O$15:$O$44; 0)); tests; XLOOKUP(s_name; 'Сводка'!$B$15:$B$44; 'Сводка'!$G$15:$G$44; ""); mock; XLOOKUP(s_name; 'Сводка'!$B$15:$B$44; 'Сводка'!$I$15:$I$44; ""); "Добрый день! Итоги на " & TEXT(TODAY(); "dd.mm") & " — " & s_name & ":" & CHAR(10) & "• посещаемость: " & n_ok & " из " & (n_ok + n_miss) & " занятий" & IF(n_miss > 0; " (пропуски: " & missed & ")"; "") & CHAR(10) & "• домашние задания: сдано " & hw_ok & " из " & hw_all & CHAR(10) & IF(tests = ""; ""; "• тесты на занятиях: в среднем " & TEXT(tests; "0%") & CHAR(10)) & "• входной пробник: " & IF(mock = ""; "ещё не написан"; mock & " б.") & CHAR(10) & CHAR(10) & IFS( n_miss >= 2; "Обратите, пожалуйста, внимание на пропуски — без занятий сложно держать темп."; hw_ok < hw_all / 2; "Сейчас главное — сдать долги по ДЗ, я помогу составить план."; mock = ""; "Ближайшая задача — написать входной пробник."; TRUE; "Всё идёт хорошо, продолжаем в том же темпе!" ) )
```

**Ученик · A14 — КЭС ученика**

```
=IFERROR(LET( k_head; 'КЭС'!$1:$1; k_row; INDEX('КЭС'!$1:$100; MATCH($B$2; 'КЭС'!$B$1:$B$100; 0); 0); TRANSPOSE(FILTER( VSTACK(ARRAYFORMULA(SUBSTITUTE(k_head & ""; "Довели до "; "")); ARRAYFORMULA(IF(k_row = 1; "✓"; "—"))); ARRAYFORMULA(REGEXMATCH(k_head & ""; "^Довели")))) ); "нет в КЭС")
```

**Ученик · D14 — Пробники ученика**

## Если что-то не считается

- **У ученика пусто или #N/A** — имя на листах написано по-разному (лишний пробел, «е»/«ё», опечатка).
- **#REF! «Массив не развёрнут»** — под формулой со списком (B15, R15, U15, Y15, AF15) что-то занято.
- **Ошибка разбора формулы** — у таблицы не русская локаль: Файл → Настройки → Регион.
- **Вместо дат числа** в блоке «Посещаемость по занятиям» — Формат → Число → Дата.
- **Шкала пробника**: ОГЭ — «3» от 8, «4» от 15, «5» от 22 из 31; база ЕГЭ — 7, 12, 17 из 21 (поменять в AB15, AC15, AD15).
